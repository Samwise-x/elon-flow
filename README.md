# Elon Flow

Self-contained engineering skills plugin, selectively derived from Pstack, Ponytail, and Matt Pocock Skills.

## Goal
Produce the smallest complete engineering capability that improves real outcomes. Source repositories are research inputs, never runtime dependencies.

## Operating contract
- Ground decisions in actual source files and the current target artifact.
- Preserve proven skills when adaptation has no demonstrated benefit.
- Remove duplication, contradictory rules, and irrelevant ceremony.
- Never invent baselines, tests, results, or verified improvements.
- Do not criticize architecture without inspecting the artifact and applicable skill.
- Stop when acceptance criteria are met.

## Status
Initial repository foundation. Upstream skill extraction and license review remain pending.
